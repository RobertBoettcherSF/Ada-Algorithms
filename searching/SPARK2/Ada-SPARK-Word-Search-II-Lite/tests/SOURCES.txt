Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: scan every row for the word left to right. A word found that
  way must be reported; a word found neither left to right nor right to left
  must not be. Words that occur only right to left are skipped (whether
  "horizontal" includes that direction is a convention the README does not
  fix). Count_Found must equal the own count when no word was skipped.
* Inputs: 5,000 random 4 x 4 boards (letters 'a' .. 'b' or 'a' .. 'd') with
  three distinct words each, about half cut from the board.
