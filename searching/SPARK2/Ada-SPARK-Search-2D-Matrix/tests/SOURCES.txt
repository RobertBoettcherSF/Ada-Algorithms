Sources of the tests in this folder
===================================

tests.adb: written with the 2026-10-09 rewrite (V&V sweep, agent B):
an 8 x 8 matrix with gaps ((K - 1) * 3 / 2 + 1 in the K-th cell, row-
major), present and absent targets at the ends, at the end of a row,
at the start of the next and between rows; a matrix whose rows hold
equal values (10 * R) with every target 0 .. 99; and the bound
floor (log2 64) + 2 on comparisons. The bound check was committed first
and fails on the old cell-by-cell scan (64 comparisons). The original
3 x 3 test is gone.

own_checks.adb (called at the end of tests.adb; written for this
repository by the V&V sweep, agent B, 2026-10-09). Reference: a scan
over every row and column of the 2D matrix (it does not use Cell); for
the predicate, rows non-decreasing and each row's last entry <= the next
row's first entry.
* Position_Of and Cell against the entries of a numbered matrix;
* 5 fixed (0 .. 63, the gap matrix, rows of equal values, all 0, all 99)
  and 200 random sorted matrices with repeats, each with every target
  0 .. 99: answer, comparisons <= floor (log2 64) + 2, measured worst
  case exactly 8;
* Sorted_Matrix membership on each with one pair of unequal row-major
  neighbours swapped (always rejected), and on 2,000 random matrices
  (half of them sorted with one entry changed).
* Random inputs use a Park-Miller generator; the default seed 20261009
  is printed, and AA_SEED=<n> overrides it.
