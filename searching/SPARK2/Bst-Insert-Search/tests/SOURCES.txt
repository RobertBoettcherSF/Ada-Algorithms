Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: after inserting a sequence of keys, Contains (V) must be
  True exactly for the inserted keys (checked for every V in -1000 .. 1000).
* Hand cases: ascending, descending and zig-zag key sequences of 1 .. 31 keys
  (chains as deep as the number of keys).
* Inputs: 6,000 random sequences of 0 .. 31 keys, any tree shape; every third
  run draws keys from -6 .. 6 so keys repeat (a repeated key is stored once).
