Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: a linear scan for the first and last index of the key
  (0 when absent).
* Checks: Find returns 0 exactly when the key is absent, otherwise an
  index inside [first, last]; Find_First and Find_Last return the scan's
  first and last indices.
* Inputs: 6000 random non-decreasing arrays (length 0 .. 30, steps 0 .. 2,
  so duplicates and gaps are common); keys -25 .. 25 (some absent).
