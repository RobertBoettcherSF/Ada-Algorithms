Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: symbol counts made in the test while generating the data;
  Count_Frequencies must match them for every symbol, Distinct_Count must be
  the number of symbols with a non-zero count, and Most_Frequent must return
  a symbol whose count is the maximum (any one of them when several tie).
* Inputs: 4,000 random arrays of length 0 .. 32, half over 'a' .. 'e' (many
  ties and repeats), half over 'a' .. 'z'.
