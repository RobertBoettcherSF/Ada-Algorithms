Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own property (README: stores each run and its count): expanding run R as
  Counts (R) copies of Output (R), for R in 1 .. Output_Length, gives exactly
  Input (1 .. Length) back; every count is at least 1; neighbouring runs have
  different characters (runs are maximal); empty input gives no runs.
* Inputs: 5,000 random strings of length 0 .. 32, half over {a, b} (long
  runs), half over {a, b, c, d}; unused positions hold '#'.
