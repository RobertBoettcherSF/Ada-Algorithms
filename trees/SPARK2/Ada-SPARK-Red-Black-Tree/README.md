# Ada/SPARK Red-Black Tree

PLACEHOLDER: the README calls this a stub / bounded kernel, not a full Red-Black-Tree implementation; see tools/readme_stubs.txt

A deliberately tiny bounded teaching stub: the color enum and a checked rotation index
are the first verified building blocks for a red-black tree. `Max_Nodes = 16`.

Run `make test` and `make prove` (Level 2, cvc5, warnings as errors).
