Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: minimum root-to-leaf depth computed recursively. A leaf is a node without children (a node with one child is not a leaf).
  Nodes vs edges: the one-node tree fixes the convention, every other tree
  must agree with it.
* Trees: random shapes with 1 .. 15 nodes rooted at node 1 (node I hangs
  below a random earlier node with a free slot), random values in -100 .. 100.
