Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: a Boolean set over the whole Value range, filled in the
  test; after the inserts, Contains must match it for every value and Size
  must equal the number of inserted values. Only distinct values are
  inserted, so how duplicates are treated does not matter.
* Inputs: 2,000 random sequences of 0 .. 31 distinct values in -100 .. 100.
