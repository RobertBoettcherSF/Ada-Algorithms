Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own property (README: greater-tree update of an array-backed BST
  sequence): for a strictly increasing in-order sequence, output I is the
  sum of all input values >= input I, computed in the test by a full scan.
  Distinct values avoid any question of how equal keys are treated.
* Inputs: 4,000 sets of 16 distinct random values in -100 .. 100, sorted.
