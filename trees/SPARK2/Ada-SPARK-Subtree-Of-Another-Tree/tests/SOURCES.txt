Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: compare the pattern with the full subtree at every node of T.
  A pattern identical to some node's whole subtree must be reported; a pattern
  that does not even fit on top of any node's subtree must not be. Patterns
  that fit on top of a subtree without being all of it are skipped (whether
  that counts is a convention the README does not fix).
* Inputs: 5,000 random trees (1 .. 15 nodes, values 0 .. 1); half the patterns
  are copies of a random node's subtree (renumbered; half of those get one
  value changed to 5), half are small random chains / cherries.
