Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: with parent links computed from the generated shape, climb from
  the deeper of the two nodes until both meet; the meeting node is the lowest
  common ancestor (no value comparisons are used).
* Trees: random shapes with 2 .. 15 nodes rooted at node 1, values assigned
  in order as distinct increasing numbers (a valid BST); the two queried values
  are taken from two different nodes (A = B is not checked).
