Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: visit every node of the tree (not only the BST-pruned ones)
  and add the values within [Low, High].
* Trees: random shapes with 1 .. 16 nodes, values assigned in order as
  strictly increasing even numbers from -98 (a valid BST). Low and High are odd,
  so whether the bounds are inclusive does not matter (the README does not say).
