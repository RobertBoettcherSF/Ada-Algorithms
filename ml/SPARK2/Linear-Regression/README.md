# Linear-Regression

`Predict (Y1, Y2, Y3, Y4, X)` fits the least-squares line through the
points (1, Y1) .. (4, Y4) and returns its value at X (1 .. 4), truncated
toward zero once at the end (the mean and slope are not rounded
separately).

`make test` runs the tests; `make prove` runs the SPARK proof.
