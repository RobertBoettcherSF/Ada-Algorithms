# Ada-SPARK-Assign-Cookies

PLACEHOLDER: the README calls this a stub / bounded kernel, not a full Assign-Cookies implementation; see tools/readme_stubs.txt

Small bounded SPARK stub for the Assign Cookies problem.

- Arrays are fixed at 32 elements or fewer.
- `make test` builds and runs the assertions.
- `make prove` runs Level 2 SPARK proof with CVC5.
