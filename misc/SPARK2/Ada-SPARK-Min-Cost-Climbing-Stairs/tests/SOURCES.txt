Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: 10 15 20 5 8 12 -> 28 (steps 2, 4, 5, then past the top), by hand.
* Own reference: start on step 1 or step 2, pay the cost of every step
  stood on, move up 1 or 2 steps at a time, finish past step 6 (the
  standard problem statement); the cheapest total over all such paths, by
  plain recursion over the choices in the test. Hand case 0 0 0 0 0 100 -> 0.
* Inputs: every cost array over {0, 1, 2} (3**6 = 729, exhaustive) and
  5,000 random arrays over 0 .. 100.
