Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: scan the values from the largest down and stop at the third
  one that occurs in the array (computed in the test).
* Inputs: 6,000 random arrays over -32 .. 32 or -32 .. -30 (few distinct
  values, many repeats); arrays with fewer than three distinct values are
  skipped, because what to return then is a convention the README does not
  fix.
* Shaped cases: 30 copies of 20 plus one 10 and one 5 at every pair of
  positions (992 cases); the third distinct value, 5, is last after sorting.
