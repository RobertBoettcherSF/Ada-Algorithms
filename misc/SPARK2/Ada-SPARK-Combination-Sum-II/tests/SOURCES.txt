Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: q (0) = 1, q (6) = 4, q (12) = 15 (the old table's values,
kept); q (13) = 18 listed by hand in the comment; q (20) = 64 and
q (30) = 296 (checked again by own_checks.adb as odd-part partition
counts). Count_Limited cases listed by hand in the comment.

own_checks.adb (every (Value, Max_Part) in 0 .. 30 x 0 .. 30, no random
inputs):
* Bitmask enumeration of every subset of 1 .. Max_Part for Max_Part <= 16.
* Euler's theorem: distinct-part partitions of n are as many as odd-part
  partitions of n, counted by multiplicity of the largest odd part; used
  for Max_Part >= Value and for Count_Distinct_Combinations.
* Complement symmetry Q (N, C) = Q (C (C + 1) / 2 - N, C) where both
  targets are in range; 0 above 1 + .. + C.
* Closed forms for Max_Part = 0, 1, 2.
* The ghost Pow2 table is regenerated by doubling, entry by entry.
