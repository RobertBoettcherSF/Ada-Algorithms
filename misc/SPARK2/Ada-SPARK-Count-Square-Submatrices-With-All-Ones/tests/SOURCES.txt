Sources of every expected value in this folder's tests
======================================================

Written by the V&V sweep (agent A3, 2026-10-09). Nothing is copied from the
program's output or from third-party test suites.

tests.adb: the first two asserts (all ones -> 16 + 9 + 4 + 1 = 30,
checkerboard -> 8) are the original ones (aggregates rewritten with []).
Hand-worked by counting K x K all-one squares for K = 1 .. 4: all zeros ->
0; a single 1 at (4, 4) -> 1; the bottom-right 2 x 2 block -> 4 + 1 = 5;
an L of three cells -> 3; a 3 x 3 block in either corner -> 9 + 4 + 1 =
14; all ones but (4, 4) -> 15 + 8 + 3 = 26 (only one 2 x 2 and one 3 x 3
square use (4, 4)); all ones but (2, 2) -> 15 + 5 = 20 (4 of the 9 2 x 2
squares and every 3 x 3 square use (2, 2)); one full row -> 4.

own_checks.adb: all 65,536 matrices against a brute-force count from the
definition (every K and every top-left corner, every cell inspected),
plus range 0 .. 30 and "only 1 x 1 squares -> number of ones".
