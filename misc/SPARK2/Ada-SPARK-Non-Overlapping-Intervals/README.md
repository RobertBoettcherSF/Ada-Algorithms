# Ada-SPARK-Non-Overlapping-Intervals

PLACEHOLDER: the README calls this a stub / bounded kernel, not a full Non-Overlapping-Intervals implementation; see tools/readme_stubs.txt

Small bounded SPARK stub for the Non Overlapping Intervals problem.

- Arrays are fixed at 32 elements or fewer.
- `make test` builds and runs the assertions.
- `make prove` runs Level 2 SPARK proof with CVC5.
