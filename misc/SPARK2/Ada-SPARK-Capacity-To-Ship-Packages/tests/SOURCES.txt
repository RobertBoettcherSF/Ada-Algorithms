Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: weights 1 .. 8 in two days -> 21 (1+..+6 = 21 | 7+8 = 15), in
  eight days -> 8, by hand.
* Own reference: every way to cut the 8 packages, in order, into at most D
  consecutive days (all 2**7 cut sets), keeping the smallest heaviest day.
* Inputs: 3,000 random weight lists (every third over 1 .. 5, so ties are
  common, the rest over 1 .. 100), every number of days 1 .. 8.
* tests.adb, capacities tried: exact counts traced by hand for a halving
  search on heaviest package .. 800 (Mid = Lo + (Hi - Lo) / 2; fits ->
  Hi := Mid, else Lo := Mid + 1); never more than ceil (log2 800) = 10.
