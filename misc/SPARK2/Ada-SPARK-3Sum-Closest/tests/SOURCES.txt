Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: the two hand examples already there.
* Own reference: every triple of distinct positions enumerated in the test;
  the result must be one of their sums (several triples may tie) and its
  distance to the target must be the smallest one.
* Fewer than three values have no triple: Length 0, 1 and 2 must be
  rejected (Constraint_Error), not answered.
* Inputs: 4,000 random arrays of 3 .. 12 values (half over -5 .. 5, so ties
  are common, half over -1000 .. 1000) with random targets; lengths 0 .. 2.
