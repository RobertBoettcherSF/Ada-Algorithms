# Ada-SPARK-Combination-Sum-IV

A small bounded Ada/SPARK exercise with SPARK_Mode enabled.

Run `make test` and `make prove` after sourcing the SPARK toolchain environment.

`Count_Ordered_Ways (N)` counts the ordered sequences of parts from the fixed
number set {1, 2, 3} that add up to `N` (`N` in `0 .. 12`; `N = 0` has one
way, the empty sequence).
