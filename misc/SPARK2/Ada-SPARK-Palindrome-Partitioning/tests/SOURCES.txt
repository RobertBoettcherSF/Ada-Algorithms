Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites.

(Folder from the seeded random sample tools/vv/sample_30.txt.)

* tests.adb: 1 2 1 (palindrome) -> 0, 1 2 2 1 -> 0, 1 2 1 3 -> the existing
  hand value.
* Own reference (standard statement): the fewest pieces over every way to
  cut A (1 .. N) into palindromic pieces, by exhaustive recursion in the
  test, minus one; the empty word needs no cut.
* Inputs: every word of length 4 over three letters (81), every N 0 .. 4.
