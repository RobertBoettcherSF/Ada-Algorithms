# Ada-SPARK-Palindrome-Partitioning

Bounded Palindrome Partitioning exercise with SPARK_Mode On and inputs limited to four elements.

```sh
make test
make prove
```

`Minimum_Cuts (A, N)` is the fewest cuts that split `A (1 .. N)` into
palindromic pieces (dynamic programming over prefixes); the empty word and
palindromes need none.
