Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: values worked by hand with the multiplicative formula
C (n, k) = n (n - 1) .. (n - k + 1) / k!: C (5, 2) = 10, C (10, 5) = 252,
C (4, 8) = 0, C (11, 3) = 165, C (20, 10) = 184_756,
C (30, 15) = 155_117_520, C (30, 1) = 30, C (30, 30) = 1, C (12, 13) = 0,
C (33, 16) = C (33, 17) = 1_166_803_110; all of row 33 against the
multiplicative formula in Long_Long_Integer and against Natural'Last.

own_checks.adb (exhaustive, no random inputs):
* Every (N, K) in 0 .. 33 x 0 .. 33 against the multiplicative formula
  in Long_Long_Integer (every partial product is C (N - K + i, i), so the
  divisions are exact); the ghost Pascal_Row spec is checked against the
  same formula with pragma Assert.
* Symmetry C (N, K) = C (N, N - K), zero for K > N, Pascal's rule, row
  sums = 2 ** N.
* Vandermonde's identity for A, B in 0 .. 15.
* The ghost Pow2 table is regenerated by doubling, entry by entry.
