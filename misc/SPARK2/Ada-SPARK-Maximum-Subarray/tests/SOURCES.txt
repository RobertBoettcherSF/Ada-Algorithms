Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: the maximum over all contiguous runs I .. J of A (1 .. N) of
  their sum, by direct summation. Whether the empty run is allowed (so an
  all-negative input gives 0) is not stated in the README; a single negative
  element fixes the convention (-5 or 0) and every other input must agree
  with it. N = 0 is not checked for the same reason.
* Inputs: every array of length 1 .. 4 over -3 .. 3 (exhaustive) and 5,000
  random arrays over -100 .. 100.
