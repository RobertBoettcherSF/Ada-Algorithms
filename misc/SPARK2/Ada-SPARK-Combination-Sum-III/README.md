# Ada-SPARK-Combination-Sum-III

A small bounded Ada/SPARK exercise with SPARK_Mode enabled.

Run `make test` and `make prove` after sourcing the SPARK toolchain environment.

`Feasible (K, N)` tells whether some set of `K` distinct digits `1 .. 9` adds
up to `N`; `Count_Choices (K, N)` returns how many such sets there are
(enumerating all 512 subsets of the digits).
