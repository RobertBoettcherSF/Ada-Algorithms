Sources of the tests in this folder
===================================

tests.adb: written with the package; three hand-written values.

own_checks.adb (called at the end of tests.adb; written for this
repository by the V&V sweep, agent B, 2026-10-09):
* Reference: fast doubling in 64-bit integers,
  F (2k) = F (k) (2 F (k + 1) - F (k)) and F (2k + 1) = F (k)**2 + F (k + 1)**2,
  a different method from the code's linear iteration; and published values
  of the sequence (OEIS A000045: F (0), F (1), F (2), F (3), F (7), F (12),
  F (19), F (25), F (31), F (32)).
* Checks: Compute (n) equals the fast-doubling value for every n in
  0 .. 32; the outputs satisfy the recurrence F (n) = F (n - 1) + F (n - 2)
  for n in 2 .. 32 and Cassini's identity F (n - 1) F (n + 1) - F (n)**2 =
  (-1)**n for n in 1 .. 31; the ten published values. 105 checks.
* No random inputs (the input domain 0 .. 32 is covered exhaustively).
