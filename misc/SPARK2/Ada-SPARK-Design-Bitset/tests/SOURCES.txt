Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

(Folder from the seeded random sample tools/vv/sample_30.txt.)

* tests.adb: hand values.
* Own reference: a Boolean array model updated in the test; membership of
  every bit and the number of members after each operation.
* Inputs: 500 random runs of 100 Include/Exclude operations.
