Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: two words are anagrams when every character occurs the
  same number of times in both (own letter counts). The label of word I
  is the number of the first word that is an anagram of it, the
  convention of the hand case in tests.adb (labels 1, 1, 3).
* Inputs: 20000 random sets of three 5-letter words over 2 .. 4 letters;
  each later word is a shuffle of an earlier one half the time.
