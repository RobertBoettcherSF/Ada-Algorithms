Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: 1 -> 2 costs 100 direct, 20 via 3 with one stop, by hand.
* Own reference (the standard statement: at most K stops = at most K + 1
  flights; Source = Destination costs 0): depth-first enumeration of every
  route of at most K + 1 flights, keeping the cheapest; Infinity (1000)
  when there is none.
* Inputs: 1,500 random sets of 16 flights on 6 cities (prices 0 .. 100,
  self-loops and parallel flights allowed), every source/destination pair,
  K = 0 .. 3 (216,000 queries).
