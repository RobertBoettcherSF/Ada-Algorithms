Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own property (README: mean and population variance of a fixed-size
  sample): Mean lies between floor (S / 5) and ceiling (S / 5), with S the
  sum of the samples; Variance lies between floor and ceiling of the exact
  population variance (5 Q - S**2) / 25, with Q the sum of squares. Both are
  computed in the test from the definitions. The README does not fix the
  integer rounding, so either direction is accepted.
* Own property: a constant sample has mean equal to the value and variance 0.
* Inputs: all 5**5 = 3,125 arrays of 5 samples over -2 .. 2 (exhaustive).
