Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: partition numbers p (0) = 1, p (5) = 7, p (12) = 77 (the old
table's values, kept), p (13) = 101 worked by Euler's pentagonal-number
recurrence in the comment, p (20) = 627, p (30) = 5_604 and p (31) = 6_842
from the same recurrence (checked again by own_checks.adb). Fewer candidates worked by
hand: parts <= 2 gives floor (n / 2) + 1, parts <= 3 the nearest integer
to (n + 3) ** 2 / 12, parts <= 1 one way, no parts only for target 0;
5 from {1, 2} listed in the comment.

own_checks.adb (exhaustive over its grid, no random inputs):
* By multiplicity: sum over the number of copies of the largest part.
* Conjugation: parts <= C equals partitions into at most C parts, counted
  by the exact-K-parts recurrence (remove a part 1, or take 1 off each
  of the K parts).
* Euler's pentagonal-number recurrence for p (n), n <= 31, against
  Count_Combinations and against Count_Limited with Max_Part >= Value.
* Closed forms for Max_Part = 0, 1, 2, 3.
* Grid: every (Value, Max_Part) with Value <= 20; for Value 21 .. 31,
  Max_Part 0 .. 3 and Max_Part = Value (the run-time check of the ghost
  P contract makes the full grid take about 8 s).
* The ghost Pow2 table is regenerated by doubling, entry by entry.
