Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: the old table of counts (1, 1, 2, 5, 14, 42, 132, 429 for
N = 1 .. 8); W (9) = 1_430 and W (10) = 4_862 by the split sum written
out by hand; W (20) = 1_767_263_190, the limit (W (21) = 6_564_120_420
> Natural'Last), continuing the same sums; All_Results for
3 - 2 * 4 + 1 (five ways evaluated by hand in the stated order:
-7, -6, 5, -4, 5), 5 * -3 - 7 (-50, -22), one operand (-99), two
operands (4 - 9 = -5) and eight factors -99 (429 ways, each
(-99) ** 8 = 9_227_446_944_279_201, the largest value allowed).

own_checks.adb (seeded: Park-Miller minimal standard generator; the
default seed is the FNV-1a (32-bit) hash of the folder name folded into
1 .. 2 ** 31 - 2 (825943755), printed; AA_SEED=<n> overrides it):
* the closed Catalan count C (2 (N - 1), N - 1) / N (exact binomials in
  Big_Integer) must equal Number_Of_Ways (N) and the ghost table
  Ways (N) for N <= 20, exceed Natural'Last for N = 21 and be 429 for
  N = 8; the ghost Bound (L) must be 99 multiplied L times, and
  99 ** 8 must fit Long_Long_Integer;
* an own shift-reduce enumerator: every sequence of N shifts and N - 1
  reductions (a reduction combines the top two parts of the stack with
  the operator between them, values in Big_Integer) is one
  parenthesization, so the sorted values must equal the sorted
  All_Results, and their number the closed count;
* an own ordered reference (recursion over the last operator, values in
  Big_Integer) must give All_Results element by element (the stated
  order);
* the all -99 and all 99 products, 99 - ... - 99, one operand, and 1,500
  seeded random expressions of 1 .. 8 operands (-99 and 99 each drawn
  with probability 1/5, otherwise uniform in -99 .. 99; uniform
  operators).
Run: gnatmake -gnata -gnatwa -gnat2022 own_checks.adb && ./own_checks
(7,571 checks, about 15 s with assertions on; without -gnata a planted
swap of the operands of "-" fails 1,924 of them).

Note: GNAT 14.2.0 hits an internal error (GNAT BUG DETECTED, trans.cc
6710) on indexing a constant Ada.Containers.Vectors of Big_Integer as
Ord (M) inside own_checks.adb; Element (Ord, M) is used instead. Not
reported upstream.
