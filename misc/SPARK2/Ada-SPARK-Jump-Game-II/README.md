# Ada-SPARK-Jump-Game-II

PLACEHOLDER: the README calls this a stub / bounded kernel, not a full Jump-Game-II implementation; see tools/readme_stubs.txt

Small bounded SPARK stub for the Jump Game II problem.

- Arrays are fixed at 32 elements or fewer.
- `make test` builds and runs the assertions.
- `make prove` runs Level 2 SPARK proof with CVC5.
