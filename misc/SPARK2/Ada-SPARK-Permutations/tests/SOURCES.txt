Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: Count (0 .. 12) are the old table's values (N!); the six
permutations of 1 2 3 listed by hand in dictionary order, then the
wrap-around; 1 3 5 4 2 -> 1 4 2 3 5 -> 1 4 2 5 3 worked by hand in the
comment (pivot, rightmost larger item, swap, reverse the tail); 5 4 3 2 1
wraps to 1 2 3 4 5 with Place reset; zero and one items.

own_checks.adb (seeded: Park-Miller minimal standard generator; the
default seed is the FNV-1a (32-bit) hash of the folder name folded into
1 .. 2 ** 31 - 2 (629188436), printed; AA_SEED=<n> overrides it):
* an own recursive generator (smallest unused item first) lists every
  permutation of N = 0 .. 6 in dictionary order; stepping from Identity
  gives the same list, Found is False exactly at the last one, and the
  step after it is the identity;
* an own rank (Lehmer code read in the factorial number system): on
  2,000 seeded random permutations of 2 .. 20 items (own Fisher-Yates
  shuffle; every 50th is the last permutation) the next permutation has
  rank + 1, and the last one wraps to rank 0; Place stays the inverse;
* Count against an own product for 0 .. 12, 13! > Natural'Last, and the
  ghost Fact_Table regenerated.
