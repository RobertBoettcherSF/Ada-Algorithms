Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: 0 -> 0, 1 -> 1, 3 -> 1, 4 -> 2, 20 -> 4, by hand.
* Own reference 1 (the puzzle itself): for N <= 3,000 the test simulates the
  N rounds (round R toggles every R-th bulb) and counts the bulbs left on.
* Own property 2 (README: number of perfect squares <= N): K = Switched_On (N)
  satisfies K*K <= N < (K+1)*(K+1), in 64-bit arithmetic.
* Inputs: every N in 0 .. 10**6, every square up to 10**9 and its
  predecessor, 100,000 random N, and 10**9.
