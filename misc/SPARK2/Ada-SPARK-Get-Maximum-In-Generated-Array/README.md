# Ada-SPARK-Get-Maximum-In-Generated-Array

An array is generated by nums (0) = 0, nums (1) = 1, nums (2 i) = nums (i)
and nums (2 i + 1) = nums (i) + nums (i + 1). What is the largest of
nums (0 .. N)?

* `Generate (N)`: nums (0 .. N), filled in index order (for I >= 2 both
  sources of nums (I) are below I).
* `Maximum (N)`: the largest entry of `Generate (N)`.

Range: N in 0 .. 1_000. The values cannot overflow (nums (I) <= I is
proved); the limit is run time with assertions enabled (the tests and
mutation runs use them): the loop invariant of `Generate` checks the whole
prefix against the ghost definition at every step, about
N ** 2 / 2 * log2 (N) steps. One `Maximum (1_000)` takes about 0.13 s,
2_000 about 0.6 s and 5_000 about 3.5 s on the sweep machine.
(The old version was a case table for N <= 16 and gave 2 for N = 5,
where nums (5) = 3.)

Proof (`make prove`, level 2, cvc5, 61 checks): `Generate (N) (I)` equals
the ghost `Nums (I)` for every I, and `Maximum (N)` is at least every
`Nums (I)`, I <= N, and equal to one of them. `Nums` is computed as the
pair (nums (I), nums (I + 1)) so that a call costs O (log I) with
assertions on; `Lemma_Rules` proves that it obeys the four rules of the
problem. No overflow anywhere.

Tests: `make test` (hand-derived values, see tests/SOURCES.txt) and
`own_checks.adb` (own simulation of the problem statement, own
binary-digit walk, powers of two against Fibonacci numbers, ghost `Nums`
regenerated; seed printed, AA_SEED overrides).
