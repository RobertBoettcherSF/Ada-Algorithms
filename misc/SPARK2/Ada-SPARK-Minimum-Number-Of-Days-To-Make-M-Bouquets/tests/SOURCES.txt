Sources of the tests in this folder
===================================

tests.adb: written with the 2026-10-09 rewrite (V&V sweep, agent B):
one bloom array (5 4 3 2 1 7 6 8) with eight (Bouquets, Size) cases
worked out by hand in the comments, one of them impossible.

own_checks.adb (called at the end of tests.adb; written for this
repository by the V&V sweep, agent B, 2026-10-09). Reference: Best, a
dynamic program over window placements (flower I starts no bouquet, or
starts one when flowers I .. I + Size - 1 have bloomed), and the first
day found by trying every day up to the latest bloom day.
* all 6,561 arrays with bloom days 1 .. 3, every Bouquets and Size in
  1 .. 8: Possible, First_Day, Possible = (Bouquets * Size <= 8);
  Count = Best for days 1 .. 3;
* 3,000 random arrays with bloom days 1 .. 1000: the same for random
  Bouquets / Size, Count = Best on each bloom day and the day before,
  Lemma_Monotone (its contracts and the checks in its body run under
  -gnata) on random day pairs, on equal bloom days and from each bloom
  day to day 1000, and Count monotone.
* Random inputs use a Park-Miller generator; the default seed 20261008
  is printed, and AA_SEED=<n> overrides it.
