Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: decode from the left; a single digit 1 .. 9 is a code, two
  digits form a code when the first is not 0 and the value is at most 26;
  count all complete splits by recursion in the test.
* Inputs: 4,000 random digit strings of length 1 .. 12 or 1 .. 29 (mostly
  1s and 2s, some 0s and larger digits) and the all-ones strings of every
  length allowed by Input (the largest count for a given length). A length
  whose count can exceed Result must not be allowed by the input type
  (lengths 30 .. 32 were allowed before and saturated silently).
