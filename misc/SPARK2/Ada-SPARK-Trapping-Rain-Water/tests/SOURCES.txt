Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: the water above column I is min (highest bar in 1 .. I,
  highest bar in I .. N) - height (I); the answer is the sum over all
  columns, computed by direct scans in the test.
* Inputs: 6,000 random height arrays of length 0 .. 32 with heights up to 3,
  20 or 1,000; positions beyond the length hold random heights, so the result
  must not depend on them.
