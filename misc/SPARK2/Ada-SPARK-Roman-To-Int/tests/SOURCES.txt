Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: our own encoder writes V in standard Roman numerals
  (greedy over M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I, the usual
  subtractive notation); To_Integer of that text must give V back. Shorter
  numerals are padded with spaces, the input format of the folder's
  existing tests.
* Inputs: every V in 1 .. 3,999 whose numeral has at most 7 letters
  (exhaustive within the input size).
