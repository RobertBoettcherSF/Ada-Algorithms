# Ada-SPARK-Create-Maximum-Number-Lite

PLACEHOLDER: only picks a maximum digit / prefix of two fixed arrays, not the full create-maximum-number algorithm; see H121

A bounded Ada/SPARK implementation of bounded maximum-number digit merge with inputs limited to at most 32 elements (8 rows/columns for the matrix).

Run `make test` for executable checks and `make prove` for level-2 CVC5 verification.
