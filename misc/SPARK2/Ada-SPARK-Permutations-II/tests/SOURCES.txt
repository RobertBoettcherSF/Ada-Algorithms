Sources of every expected value in this folder's tests
======================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Written by the V&V sweep (agent B, 2026-10-09).

tests.adb: the old table's answers as counts: 4 distinct items 24, four
items with one repeated pair 12, twelve items with one repeated pair
12! / 2 = 239_500_800; counts worked by hand (3! / 2! = 3,
4! / (2! 2!) = 6, 6! / (1! 2! 3!) = 60, all equal 1, empty 1); the
three arrangements of 1 1 2 in order and the wrap-around; 1 3 2 2 ->
2 1 2 3 worked in the comment; 3 2 2 1 wraps to 1 2 2 3; empty list;
negative values -5 0 -5.

own_checks.adb (seeded: Park-Miller minimal standard generator; the
default seed is the FNV-1a (32-bit) hash of the folder name folded into
1 .. 2 ** 31 - 2 (491898337), printed; AA_SEED=<n> overrides it):
* an own recursive generator of the distinct arrangements of a multiset
  in dictionary order (at each position each distinct value still
  available, smallest first) compared with stepping from the sorted list,
  Found exactly at the last one and the wrap to sorted, on 300 seeded
  random lists of 0 .. 7 items over 1 .. 4 values;
* Count_Distinct against the length of that enumeration and against an
  own N! / (m1! m2! ..) in Long_Long_Integer on 2,000 random lists of
  0 .. 12 items;
* the ghost Fact_Table regenerated.
* Any origin (H140, First-relative): Start and Count_Distinct on the same
  list at 'First = 5, 200 and ending at Positive'Last must give the
  origin-1 results (shown values, count, 50 Next_Permutation steps), on
  500 random lists of 0 .. 12 items (Park-Miller, seed 20261009).
