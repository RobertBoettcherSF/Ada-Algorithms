Sources of the expected values in own_checks.adb (own code, MIT)
================================================================
* Oracles with a known hidden subgroup: on Z_N (N = 2 .. 40) the oracle
  f (x) = 7 * (x mod r) + 1 is constant exactly on the cosets of H = r Z_N
  for every divisor r of N (r = N included: a one-to-one oracle hides
  H = {0}, period N), so the period is r by construction and H is the
  set of multiples of r. Solve_Abelian_HSP must return generators whose
  generated subgroup (closure under addition mod N) equals H; the answer is
  also certificate-checked with Verify_Hidden_Subgroup.
* Verify_Hidden_Subgroup: [h] is accepted iff r divides h (every h, every r).
* Evaluate_Character_Orthogonality: g * h = 0 mod N iff N / gcd (N, h)
  divides g (number-theoretic property, not the product test).
* Greatest_Common_Divisor: largest common divisor by downward search,
  0 .. 60 squared.
* Domain-only oracles (value 999 outside Z_N; identity on n bits that wraps
  at 2**n): only the domain may be read, so periods, verification and the
  "no s" answer must not change.
* Simon (n = 1 .. 5 bits, every s /= 0): f (x) = min (x, x xor s), whose
  hidden string is s by construction; s = 0 must raise Subgroup_Not_Found.
* Simon's GF(2) step called directly (Simon_Null_Vector, n = 1 .. 6): every
  s from all of s-perp and from random growing subsets of it (checked after
  each equation is added), plus 300 random equation sets per n, against a
  brute-force null space (try every x, parity of y and x by xor folding):
  one non-zero null vector -> that vector, none -> Subgroup_Not_Found,
  several -> Invalid_Oracle.
* Simon's sampling step (Simon_Sample_Equations, n = 1 .. 6, every s
  including 0): the measured support must be exactly s-perp (all y for
  s = 0, {0} for a constant oracle); y . s by the same xor-folding parity.
* End to end, n = 6 .. 8, 40 random s each with f (x) = min (x, x xor s)
  xor 165: answer s, and exactly 2**n oracle queries (no collision search);
  f (x) = x and not M is invariant under the whole span of M's bits, so a
  single-bit M gives s = M and two or more bits give Invalid_Oracle.
Nothing is taken from the program's output or from third-party test suites.
