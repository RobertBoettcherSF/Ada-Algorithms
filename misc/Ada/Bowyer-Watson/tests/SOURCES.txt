Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

(Folder from the seeded random sample tools/vv/sample_ada_30.txt.)

* Own reference geometry in Long_Float: an own monotone-chain convex hull
  (h vertices, hull area), an own orientation determinant and an own
  in-circle determinant.
* For 1500 random point sets (n = 3 .. 40, coordinates 0 .. 1000 in steps
  of 0.001), every triangle must have vertex indices in 1 .. n and
  non-zero area. No other input point may lie strictly inside its
  circumcircle (the Delaunay property). The triangle count must be
  2n - 2 - h, and the triangle areas must sum to the hull area (no gaps,
  no overlaps, hull fully covered).
