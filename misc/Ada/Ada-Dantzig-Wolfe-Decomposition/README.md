# Dantzig–Wolfe Decomposition — Ada 2023

Educational, self-contained Ada 2023 package implementing **Dantzig–Wolfe
decomposition** for block-angular linear programs. Coupling constraints stay in
a **restricted master**; each block is represented by a convex combination of
proposals (extreme points) generated by **column generation** / pricing.

Based on
[Wikipedia: Dantzig–Wolfe decomposition](https://en.wikipedia.org/wiki/Dantzig%E2%80%93Wolfe_decomposition)
(Dantzig & Wolfe, 1960). Delayed column generation is the pricing engine —
sibling **[Ada-Delayed-Column-Generation](../ada-delayed-column-generation/)**
(README link only; **no** `with`-clause dependency).

Part of the **RobertBoettcherSF** Ada algorithm series.

Language: **Ada 2023** (ISO/IEC 8652:2023), compiled with GNAT (`-gnat2022`).

## Brief history

**Dantzig–Wolfe decomposition** (1960) reformulates a structured LP by
expressing each block-feasible $x_k$ as a convex combination of extreme points
of the block polytope. The resulting master has enormously many columns;
**column generation** adds improving proposals on demand. The method is dual to
Benders decomposition in spirit and is the general framework behind delayed
column generation (e.g. cutting stock).

## Block-angular LP

$$
\min_x\;\sum_{k=1}^{K} c_k^\top x_k
\quad\text{subject to}\quad
\sum_{k=1}^{K} A_k x_k \le a,\quad
B_k x_k \le b_k,\quad
x_k\ge 0.
$$

Each block polytope $P_k=\{x_k:B_k x_k\le b_k,\,x_k\ge 0\}$ is replaced by
$x_k=\sum_i\lambda_{ki}x_k^{(i)}$ with $\sum_i\lambda_{ki}=1$, $\lambda\ge 0$.

## Restricted master

$$
\min_\lambda\;\sum_{k,i}(c_k^\top x_k^{(i)})\lambda_{ki}
\quad\text{s.t.}\quad
\sum_{k,i}(A_k x_k^{(i)})\lambda_{ki}\le a,\quad
\sum_i\lambda_{ki}=1\;(k=1,\dots,K),\quad
\lambda\ge 0.
$$

Dual multipliers $\pi\ge 0$ (coupling) and $\sigma_k$ (convexity) drive pricing.
This package encodes each convexity equality as a pair of inequalities and
solves the master as $\max(-\text{cost})$ via Bland’s rule.

## Pricing subproblem

For duals $(\pi,\sigma_k)$ of the min-form master with $\le$ coupling
(Lagrangian term $\pi^\top(Ax-a)$), the reduced cost of a proposal $x\in P_k$ is

$$
\bar c_k(x)=(c_k+A_k^\top\pi)^\top x-\sigma_k.
$$

An improving column exists when $\bar c_k(x)<0$. `Price_Block` solves the tiny
LP

$$
\min_{x\in P_k}\;(c_k+A_k^\top\pi)^\top x
$$

with the embedded simplex (blocks have at most two variables). If
$\text{Value}-\sigma_k\ge -\texttt{Tol}$ for every block, the master duals are
optimal for the full DW formulation and column generation stops.

## Algorithm sketch

1. Seed the pool with the **zero** proposal of each block.
2. **Solve_Master**: minimize over current $\lambda$ (coupling + convexity).
3. Read duals $(\pi,\sigma)$; call **Price_Block** for each $k$.
4. If an improving proposal is new and the pool is not full, **Add_Column** and
   repeat; else stop (`Optimal`, or `Column_Limit` / `Iteration_Limit`).
5. **Reconstruct_X**: $x_k=\sum_i\lambda_{ki}x_k^{(i)}$.

## Concrete toy LP

$$
\min\;-3x_1-4x_2-2y_1-5y_2
\quad\text{s.t.}\quad
x_1+y_1\le 4,\;
x_2+y_2\le 3,
$$

$$
0\le x_1\le 3,\;0\le x_2\le 2,\;
0\le y_1\le 2,\;0\le y_2\le 3.
$$

Known optimum $(x_1,x_2,y_1,y_2)=(3,0,1,3)$ with objective $-26$
(`Make_Toy_Problem` / `Toy_Optimum`).


`make` runs `gnatmake -gnatwa -gnat2022` via `dantzig_wolfe_decomposition.gpr`
(main: `tests.adb`). Expect `Pass_Count` $\ge 100$ and `Fail_Count=0`.

## Caveats

- Educational dense code: not a production DW / branch-and-price solver.
- Blocks are tiny ($\le 2$ vars); pricing uses a full tableau, not a specialized
  network/oracle API.
- Caps: $K\le 3$, coupling rows $\le 4$, pool $\le 48$; dual extraction assumes
  the slack-column path of the embedded master transform.
- No `with` of sibling packages; Bland simplex is embedded locally.
- Empty GitHub repo:
  [Ada-Dantzig-Wolfe-Decomposition](https://github.com/RobertBoettcherSF/Ada-Dantzig-Wolfe-Decomposition)
  (do not push from this workspace unless explicitly requested).
