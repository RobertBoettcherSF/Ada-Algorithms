Sources of every expected value in this folder's own tests (own_checks.adb)
===========================================================================

All checks are own properties written for this repository (MIT); nothing
is copied from the program's output or from third-party test suites.
Random inputs come from the Park-Miller minimal standard generator (seed
20261008). tests.adb predates this file.

* own_checks.adb, property (lossless compression): Decompress (Compress (X))
  returns exactly X, and no valid input raises Constraint_Error.
* Inputs: 2000 random arrays (length 0 .. 299; bytes from 3 symbols for
  many matches, or from all 256), each with three index ranges: 1 .. N,
  starting at Stream_Element_Offset'First (the bounds a positional
  aggregate gets) and ending at Stream_Element_Offset'Last.
* Found by the all-checks crash run (tools/vv/checks_on.csv): main.adb
  overflowed at lzrw.adb:43 for its aggregate input.
