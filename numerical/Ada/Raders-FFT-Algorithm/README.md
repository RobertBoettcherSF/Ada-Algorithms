# Rader's FFT Algorithm Implementation

## Project Overview
This repository contains an Ada implementation of Rader's Fast Fourier Transform algorithm. The algorithm uniquely computes the Discrete Fourier Transform (DFT) for arrays of **prime lengths** $N$ by reformulating the problem as a cyclic convolution of length $N-1$, taking advantage of number-theoretic primitives like modular inversion and primitive roots. 

## Features
- **Strong Typing Integration**: Leverages Ada's generic complex numbers and array configurations.
- **Variant 1 - Direct Convolution**: Transforms the problem structure into an $N-1$ cyclic structure using direct accumulation.
- **Variant 2 - Fast FFT Convolution**: Enhances algorithmic speed (O(N log N)) by zero-padding the cyclic convolution and applying a nested Radix-2 Cooley-Tukey processing pipeline.
- **Algorithmic Math Helpers**: In-built generic components including `Next_Power_Of_2`, `Is_Prime`, and `Primitive_Root`.
