Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference for 0 .. 60 x 0 .. 60: gcd by repeated subtraction (with
  gcd (0, b) = b). All three entry points must equal it.
* Large values (5000 random pairs sharing a random factor F up to 100000,
  products up to about 10**17): G divides both arguments, F divides G
  (every common divisor divides the gcd), the cofactors A / G and B / G
  are coprime, and Gcd_Recursive agrees.
