Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

(Folder from the seeded random sample tools/vv/sample_ada_30.txt.)

* Own reference: random expression trees over the documented grammar
  (integers 0 .. 20, + - * /, parentheses, no spaces, no unary minus),
  depth up to 4. The tree is evaluated directly (Ada integer division,
  truncating; a divisor that evaluates to 0 is replaced by a literal 1 .. 9).
  It is printed with the usual precedence and left associativity:
  parentheses where the grammar needs them, plus redundant ones at random.
* Checks: Evaluate returns the tree's value and Is_Valid accepts the text.
  The tree is evaluated in Long_Long_Integer node by node; when any node
  leaves Integer (depth 4 with literals up to 20 reaches 20**16; AA_SEED
  1, 2 and 22 each draw one such tree in 20000) Evaluate must raise
  Constraint_Error, as the spec documents, and Is_Valid still accepts.
* Fixed overflow cases (own arithmetic): 65536*65536, 2147483647+1,
  0-2147483647-2, (46341*46341)/2 raise Constraint_Error; 46340*46340 =
  2147395600 and 2147483647-1+1 = 2147483647 stay in range.
* Inputs: 20000 random expressions.
