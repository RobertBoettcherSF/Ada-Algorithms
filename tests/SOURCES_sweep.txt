Sources of expected values in the whole-repo sweep (docs/VV.md 3i)
===================================================================
All references are own code written for this repository (MIT): brute force,
recursive definitions or independent properties. No GPL/GFDL material and
nothing from Rosetta Code, LeetCode or Wikipedia text. Per-folder details are
in each folder's tests/SOURCES.txt.

strings/Ada/String-Metrics: recursive Levenshtein / OSA definitions, bigram
  sets by presence, position counts; Jaro-Winkler by properties.
misc/Ada/Dice-Coefficient: bigram sets by presence over {a, b, c}, all pairs
  up to length 5, second argument with 'First = 2.
misc/Ada/Integer-Factorization: sieve of Eratosthenes, divisor scans, binary
  gcd, double-and-add Mul_Mod, congruence definitions with plain integers.
searching/Ada/Trigram-Search: trigram sets by presence over {a, b}, all pairs
  up to length 7, second argument with 'First = 2.
misc/Ada/Poly1305: Poly1305 definition (RFC 8439 section 2.5, algorithm only)
  computed with base-256 schoolbook arithmetic; random and extreme keys,
  every two-part Update split.
misc/Ada/Unicode-Collation-Algorithm: own sort-key construction compared
  lexicographically; default, punctuation-ignoring and tailored tables.
misc/Ada/Quine-McCluskey-Algorithm: prime implicants by cube enumeration
  against the definition; minimum covers by subset enumeration /
  branch-and-bound; all functions of up to 3 variables, 1,500 random of 4.
geometry/Ada/Liang-Barsky: 4,001-point sampling of each segment with plain
  coordinate tests; helper functions against their definitions.
hashing/Ada/Geohash: integer cell indices with hand bit packing; boxes and
  neighbours from indices; all precisions 1 .. 12.
