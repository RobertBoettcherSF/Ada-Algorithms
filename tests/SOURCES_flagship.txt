Sources of expected values in the flagship checks (logic / type inference folders)
===============================================================================
All references are own code written for this repository (MIT): brute force,
certificate checkers and hand-derived expected values. Nothing is taken from
Rosetta Code, LeetCode, Wikipedia text, or GPL/GFDL material. Per-folder
details are in <folder>/tests/SOURCES.txt.

misc/Ada/Conflict-Driven-Clause-Learning: truth-table brute force, model
  certificates, planted-solution formulas, pigeonhole PHP(3,2)/PHP(4,3)
  (the pigeonhole principle encoding is folklore / public domain).
logic/Ada/Automated-Theorem-Proving: truth-table brute force, semantic
  definitions of the helpers, pigeonhole PHP(3,2)/PHP(4,3).
misc/Ada/First-Order-Logic: bit-mask enumeration of CNF encodings against the
  quantifier evaluator, substitution lemma, PHP(3,2).
logic/Ada/Verified-Unification-Engine: syntactic check of the applied unifier,
  idempotence, ground brute force for completeness and most-generality,
  clash/cycle certificates for failures.
misc/Ada/Hindley-Milner-* (both): hand-derived principal types compared up to
  alpha-renaming, ill-typed terms rejected, unifier applied and compared.
misc/Ada/Rete-Algorithm: naive enumeration of all fact tuples per rule prefix
  against beta memory sizes and activations.
misc/Ada/Darwin-Godel-Machine: demo; brute-force maximum over the candidate list
  for the selection rule only.

logic/Ada/Automated-Theorem-Proving: complete sign-pattern clause sets over 1 .. 3 of 4 variables (UNSAT), each minus one clause (SAT).
