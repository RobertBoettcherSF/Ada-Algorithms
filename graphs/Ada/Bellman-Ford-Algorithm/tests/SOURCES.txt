Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Own reference: depth-first enumeration of every simple path from the
  source (minimum cost per target) and of every simple cycle through each
  reachable vertex (is any of them negative?), with n <= 6.
* Checks: Status = Negative_Cycle and Has_Negative_Cycle exactly when a
  reachable negative cycle exists. Otherwise Dist equals the minimum
  (Infinity when unreachable), and the Prev tree gives paths of exactly
  that cost.
* Inputs: 4000 random digraphs, up to 3n edges, weights -4 .. 20
  (negative self-loops are left out).
