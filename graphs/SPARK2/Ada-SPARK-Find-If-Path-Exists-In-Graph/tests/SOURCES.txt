Sources of every expected value in this folder's own tests (tests.adb, own_checks.adb)
=====================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: edges 1->2, 2->3: 1 reaches 3, 3 does not reach 1, by hand.
* Own reference: transitive closure of the edge matrix by Warshall's
  algorithm, with every vertex reaching itself.
* Inputs: 600 random graphs on 16 vertices (edge density 0 .. 30 %, every
  second one made symmetric, i.e. the undirected exercise), every
  start/goal pair (153,600 queries).
