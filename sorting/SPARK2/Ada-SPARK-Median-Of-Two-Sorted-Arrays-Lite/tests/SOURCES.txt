Sources of the tests in this folder
===================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites.

tests.adb: written with the 2026-10-09 rewrite (V&V sweep, agent B):
the original example (1 3 8 10 / 2 4 9 12, median 6) padded to 16
values each with six 0s below and six 50s / 60s above (the middle values
stay 4 and 8), one array wholly below the other in both orders, odd /
even interleaved, all equal, and the bound floor (log2 32) + 2 = 7 on
comparisons. The bound check was committed first and fails on the old
selection sort (496 comparisons for 32 values).

own_checks.adb: first written by the earlier own-tests batch for the
4-element version (random pairs against an insertion-sort median,
rounding not checked); rewritten by the V&V sweep, agent B, 2026-10-09,
for the 16-element version. Reference: all 32 values sorted by insertion;
Lower and Upper must be the 16th and 17th, Median their mean rounded down
(the rounding is now part of the contract).
* 3,000 random pairs over 0 .. 100, 3,000 over 0 .. 3 (many ties), 500
  with Left below Right and 500 with Right below Left: answer, comparisons
  <= 7, measured worst case exactly 6 (5 comparisons in the search only
  when it moves left every time, which ends at I = 0 where no more are
  needed);
* exact counts worked by hand: Left wholly below Right 4, Right wholly
  below Left 5, all equal 5; and (added after the held-out mutation run,
  whose 13 real survivors were counter mutants in the Lower / Upper
  choice) three paths with one comparison in each choice: Left odd /
  Right even 6, Left even / Right odd 6, and a J = 1 cut 6;
* Sorted_Array membership against a neighbour-by-neighbour test on 3,000
  random arrays (half sorted with one entry changed).
* Random inputs use a Park-Miller generator; the default seed 20261008
  is printed, and AA_SEED=<n> overrides it.
