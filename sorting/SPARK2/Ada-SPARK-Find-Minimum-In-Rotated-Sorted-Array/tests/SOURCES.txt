Sources of the tests in this folder
===================================

tests.adb: written with the 2026-10-09 rewrite (V&V sweep, agent B):
three arrays (turned by 13, not turned, turned by one) with their
minimum positions worked out by hand.

own_checks.adb (called at the end of tests.adb; written for this
repository by the V&V sweep, agent B, 2026-10-09). Reference: a linear
scan for the smallest value, and the known rotation (each array is a
known increasing Base turned by S places, so Base (1) must be at
position ((32 - S) mod 32) + 1).
* all 32 rotations of 4 fixed increasing arrays and of 300 random
  increasing arrays (32 distinct values out of 0 .. 100): position,
  value at the position, 5 probes, Minimum;
* Is_Rotated_Sorted against a second rule (exactly one cyclic
  non-increasing step) on the rotations, on rotations with two
  neighbours swapped or one value copied onto its neighbour, and on
  2,000 random arrays.
* Random inputs use a Park-Miller generator; the default seed 20261008
  is printed, and AA_SEED=<n> overrides it.
