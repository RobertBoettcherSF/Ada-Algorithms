Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Interpretation (from the function name and README "Merge Sorted Array"): the
  result is the sum of the first Length values of the merged sequence of the
  two sorted arrays.
* Own brute-force reference: concatenate both sorted arrays, sort with an own
  insertion sort, sum the first Length values.
* Inputs: every Length 0 .. 32, 100 random pairs of sorted arrays each over the
  full Value range and 100 over -2 .. 2.
