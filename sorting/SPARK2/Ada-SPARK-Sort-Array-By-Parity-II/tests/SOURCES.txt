Sources of every expected value in this folder's own tests (own_checks.adb)
==========================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* Property: Output (I) mod 2 = I mod 2 (odd values at odd positions, even at
  even positions) and Output is a permutation of Input.
* Inputs: 3,000 random arrays with exactly four even and four odd values,
  randomly shuffled (the only inputs for which the placement is possible).
  Inputs with an unequal split are outside the exercise and not checked.
