Sources of every expected value in this folder's tests (tests.adb, own_checks.adb)
==================================================================================

All checks are own properties or own reference code written for this
repository (MIT); nothing is copied from the program's output or from
third-party test suites. Random inputs come from the Park-Miller minimal
standard generator (seed 20261008).

* tests.adb: -4 -1 0 3 10 10 .. 10 -> 0 1 9 16 100 .. 100, worked out by hand.
* Own reference (own_checks.adb): square every element, then sort with an own
  insertion sort; for a sorted input, Squares must return exactly that.
* Inputs: ascending with extremes, constants, zeros, a symmetric array, and
  3,000 random arrays sorted by the own insertion sort.
* Rejection: an unsorted input (a descending array, ~500 random arrays) must
  be refused by the input type (Assertion_Error under -gnata).
