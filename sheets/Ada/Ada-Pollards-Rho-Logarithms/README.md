# Pollard's rho algorithm for logarithms — Ada 2023

Educational, self-contained Ada 2023 package for **Pollard's rho algorithm
for logarithms** (John Pollard, 1978): solve the discrete logarithm
$\alpha^{\gamma}=\beta$ in a cyclic group of known order $n$ by iterating a
pseudorandom map on $x=\alpha^{a}\beta^{b}$ and recovering $\gamma$ from a
Floyd cycle collision. See
[Wikipedia: Pollard's rho algorithm for logarithms](https://en.wikipedia.org/wiki/Pollard's_rho_algorithm_for_logarithms).

This is **not** Pollard's rho for **integer factorization** (that sibling is
**[Ada-Pollards-Rho](https://github.com/RobertBoettcherSF/Ada-Pollards-Rho)**).
Same cycle / “rho” intuition, different problem (DLP vs factoring).

Language: **Ada 2023** (ISO/IEC 8652:2023), compiled with GNAT (`-gnat2022`).

Part of the **RobertBoettcherSF** Ada algorithm series.

## Algorithm

Given a cyclic group $G=\langle\alpha\rangle$ of order $n$ and $\beta\in G$,
Pollard's rho for logarithms builds a sequence

$$
x_i=\alpha^{a_i}\beta^{b_i}
$$

with a “random-looking” update $f$ that partitions $G$ into three sets. This
package uses the rem-$3$ map matching Wikipedia's worked table:

$$
\begin{aligned}
x\equiv 0\pmod{3} &\Rightarrow x\leftarrow x^{2},\; a\leftarrow 2a,\; b\leftarrow 2b \\
x\equiv 1\pmod{3} &\Rightarrow x\leftarrow \alpha x,\; a\leftarrow a+1 \\
x\equiv 2\pmod{3} &\Rightarrow x\leftarrow \beta x,\; b\leftarrow b+1
\end{aligned}
$$

(all exponent arithmetic modulo $n$). Floyd's tortoise/hare finds $i$ with
$x_i=x_{2i}$, i.e.

$$
\alpha^{a}\beta^{b}=\alpha^{A}\beta^{B}.
$$

Substituting $\beta=\alpha^{\gamma}$ yields the linear congruence

$$
(B-b)\gamma\equiv(a-A)\pmod{n}.
$$

Solutions come from the extended Euclidean algorithm / modular inverse. When
$\gcd(B-b,n)=d>1$, up to $d$ candidates are checked with
$\alpha^{\gamma}\equiv\beta$; the verifying $\gamma$ is returned.

Heuristic length of the rho is about $\sqrt{\pi n/8}$, so expected time is

$$
O(\sqrt{n}).
$$

Combined with Pohlig–Hellman this becomes $O(\sqrt{p})$ in the largest prime
factor $p$ of $n$ (sibling topic).

### Wikipedia classroom example

Group generated by $\alpha=2$ modulo $N=1019$ (order $n=1018$), target
$\beta=5$. The collision at $i=51$ produces the congruence
$38\gamma\equiv 380\pmod{1018}$, whose solutions include $\gamma=10$ and
$\gamma=519$; only $\gamma=10$ satisfies $2^{10}\equiv 5\pmod{1019}$.

## What the code actually does

### Helpers

`Mul_Mod` multiplies via `Unsigned_128`. `Mod_Pow` is binary
exponentiation. `Gcd` / `Modular_Inverse` finish the congruence (self-contained
extended Euclidean on `Long_Long_Integer`). `Sub_Mod` is non-negative modular
subtraction.

### `Discrete_Log_Rho`

Floyd loop on the rem-$3$ partition; solve $(B-b)\gamma\equiv(a-A)\pmod{n}$;
verify candidates. Returns $\gamma\in\{0,\ldots,n-1\}$ or the failure
sentinel $n$ (`Order`). `Seed` sets the initial $\alpha$-exponent $a_0$
(classic start: `Seed => 0`). Raises `Invalid_Argument` for bad inputs or
order above `Max_Educational_Order`.

## Limits and caveats

- Educational `U64` toy — **not** a cryptographic discrete-log solver.
- Expected $O(\sqrt{n})$ only in the heuristic / birthday sense; unlucky
  partition or seed returns the sentinel `Order` (retry another `Seed`).
- Distinct from **Ada-Pollards-Rho** (factorization).
- Next educational rows: **Pohlig–Hellman**, **BSGS**, **index calculus**.
